# 润色前检索历史文章

在 raw/source.md 已就绪、尚未润色正文时执行。此步骤属于内容检索，与作者语气缓存独立：语气缓存命中仍需为新稿查询相关内容，但不把搜索命中的文章全当作新语气样本。

## 找候选，再确定是否值得引用

AI 先从原稿提取 2–5 个具体概念、技术对象或读者问题，分别搜索：

```bash
python3 <skill>/scripts/related_posts.py --query 幂等 重复消费 分布式锁 --exclude <当前slug> --limit 8
```

脚本按标题、描述、话题、章节与正文的字面命中返回有限候选和相关片段；不会代替语义判断，也不会自动把高分结果插进正文。查询中文词组及常见中英别名，避免只搜“技术/AI/总结”。不要求用户先指定历史文章。

- 读取最相关候选的命中段落和必要上下文，判断是补充背景、解释术语、提供实现细节还是只是碰巧同词。通常选 1–3 篇即可；没有有价值的关联就不插，不按数量凑推荐。
- 排除本篇、自引草稿、未来日期、受密码保护的文章。脚本的本地文件和推算路由不能证明已发布。实际打开候选 URL，核对文章对象、正文与最终地址，排除跳到首页的软 404；必要时核对章节锚点。
- 线上标题可能早于本地修订，引用以已发布页面的可识别标题/主题为准。不把待发布的本地新增内容写成“我之前讲过”。旧文只提供延伸材料，错误或过时知识仍按当前权威依据核查。
- 默认在正文首次解释相关概念处自然插入，例如“重复投递的处理方式，可以结合[之前的幂等方案](实际链接)看”。不是每个技术词都挂链接；同一篇默认只引用一次。
- 需要一并比较、但不适合打断正文时，在文末加简短“延伸阅读”，每篇用真实标题和一句具体关联说明。正文已有自然引用时不再重复列同一份推荐。
- `correction-only` 可把现有相关词语加上历史链接；不要新增长段回顾或论点。用户要求严格不改结构时，延伸阅读建议放在 review 记录，不擅自新增章节，并将未插入原因写入 review_note（selected 留空）。

## 微信与英文

微信 Markdown 保留已选历史文章及其有意义的名称。已有经核验的同篇公众号 URL 时，可在链接文字旁额外提供公众号版本，并保留博客原始来源；不能根据博客 slug 猜出公众号链接。默认普通博客外链由渲染器转成编号引用和可复制地址，公众号内文章链接保留锚文本。实际能否跳转以账号与草稿预览为准，不写虚假的“点击这里”。

英文版遵守 publishing-plan.md 的语言路由规则：有真实英文译文才引用英文 URL，无译文则按既有契约说明原文语言。不要将中文标题直接配给不存在的 /en/ 页面。

## 可恢复记录

新项目启用 metadata.related_posts_contract_version: 1。在 draft/related-posts.json 保存选择结果，并由 editorial-review.json.artifacts 绑定文件指纹。旧项目按需添加版本字段再补记录；缺少该字段保持兼容。

```json
{
  "source_sha256": "raw/source.md 当前 SHA-256",
  "queries": ["幂等", "重复消费"],
  "review_note": "选择解释重复消息处理的旧文，其他仅提到相同词的文章不采用",
  "selected": [
    {
      "source_path": "source/_posts/<old-slug>.md",
      "source_sha256": "候选原文件当前 SHA-256",
      "url": "https://本站/实际文章路由/",
      "label": "已核对的文章名或具体主题",
      "relevance": "命中段落补充了新稿略去的哪项知识",
      "placement": "正文首次解释重复消费的段落",
      "publication_check": {
        "status": "verified",
        "url": "https://本站/实际文章路由/",
        "checked_at": "实际核查日期",
        "evidence": "打开页面后核对的文章标题、正文特征与路由；不是只检查 HTTP 200"
      }
    }
  ]
}
```

没有合适或可核实的已发表文章时 selected 为 []，明确写未选原因。selected 中的链接必须出现在 polished.md 及已选微信的 wechat.md；不能记录选中后却遗漏链接。原稿、历史文章或选取记录改变时重新检查并复审。
